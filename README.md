La Quête des Gueux

Bienvenue dans le prestigieux royaume des gueux (prestigieux… enfin, tout est relatif).
Un trésor légendaire y est caché, derrière un labyrinthe si tordu qu’on se demande si son architecte n’avait pas trop bu.

Pour l’atteindre, il faudra d’abord récolter trois indices éparpillés dans le royaume. Ensuite, la clé en main, affrontez le labyrinthe et dénichez deux derniers indices avant de mettre la main sur le fameux trésor… et surtout, retrouver la sortie.
